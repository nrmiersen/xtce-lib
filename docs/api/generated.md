# Generated Schema Models

`xtce_lib.generated` contains xsdata-generated, version-specific schema models. Use the [unified XTCE model](xtce.md) for a version-agnostic API. The generated modules are useful when working directly with the corresponding XML schema bindings.

```python
from xtce_lib.generated import xtce_1_1, xtce_1_2, xtce_1_3
```

- `xtce_1_1`: XTCE 1.1 schema bindings.
- `xtce_1_2`: XTCE 1.2 schema bindings.
- `xtce_1_3`: XTCE 1.3 schema bindings.
